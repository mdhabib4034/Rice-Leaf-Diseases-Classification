# 🌾 Rice Leaf Disease Identification

A deep learning project for identifying rice leaf diseases using Convolutional Neural Network (CNN).

## 📌 Project Overview

This project focuses on the identification and classification of rice leaf diseases from images using deep learning techniques.

The model is trained using a rice leaf disease image dataset containing three disease classes.

## 🦠 Disease Classes

The project includes the following rice leaf disease classes:

- Brown Spot
- Bacterial Blight
- Leaf Smut

## 📊 Dataset

The dataset contains rice leaf images categorized into three disease classes.

The dataset was processed and prepared for model training, validation, and testing.

## 📊 Dataset

The dataset contains rice leaf images belonging to three disease classes:

- Brown Spot
- Bacterial Blight
- Leaf Smut

Due to the large size of the image dataset, the complete dataset is not included in this repository.

The project uses a Convolutional Neural Network (CNN) for image classification.
